# atlas_assistente
este projeto é brasileiro!, basicamente é um assistente atlas que usa o gemini para funcionar, você pode expandi-lo, ou usa-lo assim mesmo, e não precisa de api, ele abre uma aba no edge e só precisa colocar a conta do gemini.
após ligar o assistente ele vai abrir uma aba no edge, você deve colocar sua conta do gemini(é o site oficial), se você ainda tiver cotas na sua conta oficial do Gemini poderá usar, até da para reconhecer imagens!, há falas pré prontas tipo "iniciar playlist" que iniciar playlist se você tiver colocado os audios em MP3 na pasta certa
este é um prototipo v1, então ainda há erros e queremos que sitem eles para nos 
o atlas3.0 é com o modelo gemma3:1b ou seja roda 100% ofline, mas precisa de um pc intermediario, baixar o ollama e dar windons + r depois cmd e depois no cmd "ollama pull gemma3:1b" sem as aspas, esse é meio burro 

temos o atlas_9b.py, para computadores bons, precisa fazer o mesmo que o outro mas dar "ollama pull gemma2:9b" sem aspas no terminal

e temos o atlas_70b esse modelo chega perto do chatgpt mais antigo, é ofline, precisa de um pc muito bom para rodar, se pá até um servidor
você baixa com "ollama run llama3.3:70b" mas ele é muito pesado mesmo!!!!!!!!!!
